# NLLB-3.3B supersedes NLLB-200-distilled-600M

**Date:** 2026-05-25 (Phase 1.3 — commit `9c9f219`)
**Status:** locked as active translator

## Context

Phase 0 ran the smaller distilled NLLB (600M) as the only translator on the CPU/Mac pass. The verdict's quality table showed:

| metric             | overall | cartoon | proper | narration | idiom |
| ------------------ | ------: | ------: | -----: | --------: | ----: |
| meaning_preserved  | 3.33    | 4.00    | 5.00   | 2.10      | 1.33  |
| register           | 3.15    | 3.56    | 4.88   | 2.20      | 1.33  |
| naturalness        | 3.12    | 3.38    | 4.50   | 2.60      | 1.50  |

Narration and idioms were unusable. The verdict explicitly named "GPU re-eval with NLLB-3.3B" as the expected next step.

## Decision

Use `facebook/nllb-200-3.3B` as the Phase 1 default translator. Same loader as the 600M candidate (the only difference is `model_id` and dtype). Runs on MPS at fp32 within the 32 GB Mac budget when configured with `max_new_tokens=512`, `num_beams=4`, `no_repeat_ngram_size=3`.

## Consequences

- Idiom and Russian-narration quality improved enough to ship without a separate idiom fix.
- ~6.6 GB resident; fits the 32 GB Mac with headroom for the other stages.
- The 600M distilled candidate stays registered in `patmir.toml` (status: superseded) but is not the active default.

## Revisit trigger

When Qwen3-Instruct-MLX (already registered as a candidate in `qwen3_instruct_mlx.py` with the system prompt "You preserve tone, register, and emotion") has been ear-judged against NLLB-3.3B on the masha clip. Qwen3's prompt-driven emotion preservation is also the path for emotion-aware translation; if Qwen3 wins, it becomes the default and the emotion plumbing already in place automatically activates.
