# NLLB-200-3.3B (translate)

- **Repo / version:** `facebook/nllb-200-3.3B`
- **Parameters / size / runtime memory:** 3.3B params; ~6.6 GB resident at fp32 on MPS
- **Quantization available:** fp16 / bf16 work; int8 via bitsandbytes (CUDA only)
- **Apple Silicon (MPS):** ✅ via Transformers
- **CUDA:** ✅ recommended for larger throughput
- **Languages:** 200; Eastern Armenian as `hye_Armn`
- **License / gating:** CC-BY-NC 4.0 — non-commercial personal use is OK
- **Integration surface:** `patmir/eval/candidates/translation/nllb_200_distilled_600m.py` (shared loader)
- **Status in pipeline:** **active** since Phase 1.3 (commit `9c9f219`)
- **Last evaluated:** 2026-05-25 (Phase 1.3)
- **Our experience:** Idioms and Russian-narration improved noticeably over the 600M distilled (which scored 1.33 / 1.20 on those categories in Phase 0). Cartoon dialogue is reliably watchable.
- **Notes:**
  - 4 beams + `no_repeat_ngram_size=3` are tuned for the Phase 0 eval set; revisit if a category regresses.
  - Same loader as the 600M candidate — model swaps are config-only.
