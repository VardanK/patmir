## Foundational (project setup)

- **2026-05-24 — [Eastern Armenian only](decisions/2026-05-24-eastern-armenian-only.md).** Target dialect is `hy_AM`; Western Armenian (`hyw`) outputs are automatically rejected. *Revisit:* never (this is a product scope decision tied to the target user).
- **2026-05-24 — [Local-first strict](decisions/2026-05-24-local-first-strict.md).** Cloud APIs are never enabled by default; cloud is a per-stage opt-in fallback only after the local set for that stage is judged inadequate. *Revisit:* if cloud becomes free *and* private *and* offline-capable (unlikely).

Kept as the no-ref fallback after the OmniVoice swap. *Revisit:* if Piper produces unusable output for a real episode, or if a meaningfully-better EA fine-tune appears.

- **2026-05-25 — [OmniVoice MLX supersedes Piper as the active TTS](decisions/2026-05-25-omnivoice-supersedes-piper.md).** OmniVoice's zero-shot ref-clip cloning produces hy_AM cleanly, gives per-character voice variety automatically, and is the foundation Phase 2 multi-voice depends on. Piper stays as the fallback when no ref clip is available for a speaker. *Revisit:* if a stronger EA-capable local TTS appears (see the on-demand `stages/tts/` rejection files for the current survey).

## Phase 2.x (emotion transfer + auto-loaded docs — this spec)

- **2026-05-26 — [OmniVoice locked for Eastern Armenian](decisions/2026-05-26-omnivoice-locked-for-ea.md).** F5-TTS-MLX (335M, MLX-native, but EN+ZH only, no EA fine-tune) and IndexTTS-2 (PyTorch-only, ZH/EN/JA/ES only, 8-dim emotion vector but no Armenian) both fail the EA gate. OmniVoice MLX remains the only verified-working EA local TTS. *Revisit:* an EA fine-tune of F5-TTS-MLX appears, OR cloud TTS (ElevenLabs / OpenRouter Multilingual v2) is approved per the local-first exception policy.
- **2026-05-26 — [Emotion routed through ref-clip binning](decisions/2026-05-26-emotion-routed-through-ref-clip-binning.md).** Since OmniVoice has no explicit emotion knob, emotion transfer routes through (a) detecting per-sentence source emotion with emotion2vec, (b) picking per-`(speaker, emotion_bin)` ref clips, (c) tuning `guidance_scale` per bin, (d) injecting the emotion tag into Qwen3's user prompt when active. Emotion fidelity is bounded by what's audible in the source character's range — accepted constraint. *Revisit:* if OmniVoice exposes an explicit emotion knob, or if the TTS engine is swapped.
- **2026-05-26 — [Auto-loaded architecture docs](decisions/2026-05-26-auto-loaded-architecture-docs.md).** Two-tier `docs/architecture/` structure. Always-loaded tier (`pipeline.md`, `current-models.md`, `decisions.md`, `quality-issues.md`) imported by `CLAUDE.md` via `@`-imports; on-demand tier read by the agent when working in that area. The `CLAUDE.md` "Maintenance contract" names which docs to update for which action. *Revisit:* if `CLAUDE.md` becomes too large to auto-load efficiently, or if a better local-knowledge mechanism replaces `@`-imports in Claude Code.
- **2026-05-26 — [Prefer fast/nearby model-host mirrors](decisions/2026-05-26-prefer-fast-model-mirrors.md).** When adding any new model candidate, default to the fastest mirror (HF > GitHub releases > major CDNs > project servers > ModelScope > university hosts). For libraries that default to a slow hub (funasr → ModelScope is the canonical example), override in the candidate's `build()`. Caught after a 43-min ModelScope download crawled at 600 KB/s before being switched to a Cloudflare-fronted HF mirror. *Revisit:* only the per-model exception path applies — the rule itself doesn't revisit.
- **2026-05-26 — [Cloud translate via OpenRouter (Gemini 2.5 Flash default)](decisions/2026-05-26-cloud-translate-via-openrouter.md).** Per-stage cloud opt-in for translate after the local TTS + emotion-routing chain still ear-tested flat on the masha clip. NLLB-3.3B's register-neutral phrasing is the secondary contributor to the flatness; frontier LLMs prompted with the per-sentence emotion tag produce more dynamic Armenian word choice. OpenRouter chosen as the gateway to multiple frontier models (Gemini Flash active, Claude Opus 4.7 + GPT-5 registered as alternates) behind one API key. *Revisit:* if frontier output isn't meaningfully better than NLLB on a representative clip, revert to local; if a frontier-quality local Armenian LLM appears (HyGPT-10b-it, 70B EA fine-tune), revert to local.
- **2026-05-26 — [ElevenLabs Multilingual v2 (attempted, blocked on Free tier)](decisions/2026-05-26-elevenlabs-tts-cloud-opt-in.md).** First cloud-TTS attempt; blocked by Free-tier API restrictions (no library voices via API, no IVC — Creator $22/mo required). Candidate registered (`enabled = false`) as a future option if a Creator-tier key arrives. **Superseded by the OpenRouter TTS route below.**
- **2026-05-26 — [OpenRouter TTS via Gemini 3.1 Flash (active TTS)](decisions/2026-05-26-openrouter-tts-cloud-opt-in.md).** Per-stage cloud TTS via the OpenAI-compatible `/v1/audio/speech` endpoint on OpenRouter (same `OPENROUTER_API_KEY` as translate). Default model is `google/gemini-3.1-flash-tts-preview` — 200+ inline audio tags (`[happy]`, `[sad]`, `[angry]`, etc.), injected per sentence from `s.emotion`. Per-speaker voice rotation across Gemini's prebuilt voices (Kore / Puck / Aoede / Charon / Leda / Orus) preserves multi-character variety. Ear-tested 2026-05-26 as "much better than what we had, not as good as ElevenLabs" — acceptable. *Revisit:* if a Creator-tier ElevenLabs key arrives, cost runs high, Gemini's Armenian regresses, or an EA emotion-controllable local TTS ships.
- **2026-05-27 — [Scribe v2 for ASR + diarize](decisions/2026-05-27-scribe-v2-for-asr-and-diarize.md).** Swap both stages to a single `elevenlabs_scribe_v2` candidate after pyannote (3.1 and community-1) repeatedly merged short cartoon turns from distinct characters into one `SPEAKER_NN` on masha-2-5min. Scribe v2 returns words + per-word `speaker_id` in one call; result is cached at `<job>/scribe/result.json` so the two stages share a single upload. Local Whisper + pyannote stay registered as alternates. *Revisit:* if Scribe regresses on Russian, if overlap-aware ref picking becomes load-bearing, if cost runs hot on full episodes, or if a stronger local diarizer ships.
- **2026-05-26 — [Cloud ASR via OpenRouter (gpt-audio + MMS-FA alignment)](decisions/2026-05-26-cloud-asr-via-openrouter.md).** Per-stage cloud opt-in for ASR. Original plan (`gpt-4o-transcribe` via `/v1/audio/transcriptions` with native word timestamps) failed at smoke probe — that endpoint doesn't exist on OpenRouter (verified 2026-05-26; 4 transcribe-SKU model ids 500 out, none in the catalog). Pivoted to chat-completions multimodal audio (`openai/gpt-audio`) with mandatory local forced alignment via MMS-FA (`ctc-forced-aligner`). First ear-test exposed a CTC-alignment failure mode: cloud model transcribed long screaming/laughing sections as hundreds of repeated `А-а-а!` tokens that dominated the alignment and crushed dialogue into tiny windows. In-spec fix: prompt the cloud model to skip non-lexical vocalizations + strip non-lexical lines from the transcript before alignment. Voxtral Small 24B + GPT Audio Mini + GPT-4o Audio Preview registered as disabled alternates. ElevenLabs Scribe v2 registered as a policy-gated documentation-only future option. Local Whisper-MLX kept as offline fallback. *Revisit:* if cost runs high, if Scribe is ear-tested + approved, if a native-timestamp OR-routable STT appears, or if Russian quality regresses on a representative episode.

## Phase 2 finalization (low-friction UX — this spec)

- **2026-05-27 — [Low-friction translation UX uses D1 (pre-process + cache)](decisions/2026-05-27-low-friction-translation-d1.md).** Phase 2 finalization ships an MV3 Chrome extension + local FastAPI server that wraps the current batch pipeline with URL-keyed caching at `~/.patmir/cache/<key>/`. Real-time / stream-replace (D3) rejected: the runner is strictly sequential and ~0.64× realtime, so a 30 s buffer cannot cover the ~280 s before the first TTS sentence; D3 would also unwind Phase 2.x global-diarization + global-ref-clip-picking assumptions and regress quality. DRM streams (Netflix / Prime / Disney+) explicitly out of scope (extensions can't read EME-protected MSE buffers). *Revisit:* if streaming Demucs + EA streaming TTS appear (reopen D3), if cache size grows unmanageable (ship LRU), if single-view usage dominates over rewatch (rethink the wait UX), or if a system-audio DRM bridge becomes interesting (different product). **→ D3 reopened 2026-06-13; see below.**

## Phase 3 (near-realtime watch-along)

- **2026-06-20 — [Higgs Audio v3 TTS (4B) via MLX-q8 port](decisions/2026-06-20-higgs-v3-tts-mlx-q8.md).** Active **batch** TTS swapped from OmniVoice to `higgs_v3_mlx_q8` — first local EA TTS with real inline emotion control (`<|emotion:..|>`) + cloning; faster than OmniVoice-32 (agg RTF 1.10 vs 1.69) and better quality. Hybrid runtime: our MLX port of the Qwen3-4B backbone (q8) + PyTorch codec on MPS (decode is bandwidth-bound → quantization is the only lever; torch.compile doesn't help). Guardrail for known non-termination: temp 0.8 + length-cap + reseed (measured: LOW temp causes overflow, not high). **Watch-along also switched to Higgs** (`higgs_v3_mlx_q8_fast`) for engine consistency despite RTF 1.10 > OmniVoice-16's 0.91 — leans on the pre-buffer; prefix-KV caching is the follow-up. q4 rejected (collapses). *Revisit:* mlx-audio #766 ships a runtime, prefix-KV caching lands, EA/emotion regression on a clip, or the non-commercial license becomes a constraint.
- **2026-06-19 — [Vocals-only separation](decisions/2026-06-19-vocals-only-separation.md).** Batch `separate` runs only `htdemucs_ft`'s vocals-specialist sub-model (sig `04573f0d`) instead of the full 4-model bag; `accompaniment = mix − vocals`. Quality-neutral on vocals (the ft bag's vocals come 100% from this sub-model — identity weight matrix; ear-confirmed corr 0.998), ~3.6× faster on the stage (39→11 s/60s), dropping the pipeline to ~1.07× realtime. New candidate `htdemucs_mlx_vocals`; full `htdemucs_mlx` bag stays registered. *Revisit:* dirty residual bed on some clip, or switching watch-along to it too.
- **2026-06-15 — Demucs separation moved to MLX.** `separate` swapped from PyTorch Demucs (MPS) to `demucs-mlx` (`htdemucs_mlx` batch / `htdemucs_mlx_fast` watch-along) — Apple-Silicon-native, same `htdemucs_ft` model + identical `SeparatedAudio` output contract (only the engine changed; VAD split + artifact writing are shared). PyTorch `htdemucs`/`htdemucs_fast` stay registered as fallbacks. *Revisit:* if MLX separation regresses vs PyTorch on a clip, or on a CUDA box (MLX is Apple-only). See `stages/separate/htdemucs-mlx.md`.
- **2026-06-15 — [Local ASR + diarize (and watch-along TTS) via mlx-audio](decisions/2026-06-15-local-asr-diarize-via-mlx-audio.md).** ElevenLabs credits exhausted → moved off cloud Scribe v2: ASR → `nemotron_mlx` (NVIDIA Nemotron 3.5 streaming, native word/sentence timing, auto-detect), diarize → `sortformer_mlx` (NVIDIA Sortformer, end-to-end, ≤4 speakers, re-derives overlaps), both via mlx-audio; watch-along TTS → local `omnivoice_mlx_q8_fast` (off `elevenlabs_pool`). `mlx-community/OmniVoice-8bit`/`bf16` rejected (won't load / no reliable cloning). Whisper-MLX + pyannote stay registered as fallbacks; translate (OpenRouter) is the only remaining cloud stage. *Revisit:* Nemotron Russian quality, Sortformer >4 speakers, OmniVoice realtime in D3, or ElevenLabs credits return.
- **2026-06-13 — [Near-realtime watch-along (D3): spike GO + architecture](decisions/2026-06-13-near-realtime-d3-spike.md).** Author reopened D3. Throughput spike found the pipeline is 0.25× realtime with TTS as the sole gate, and two fixes clear it: ElevenLabs `eleven_v3` (~1.57 s/sentence, clears realtime at full quality, 3-concurrent cap) or OmniVoice with a configurable `num_steps` (8 = realtime, reduced fidelity; MLX can't parallelize). Ships as an **additive watch-along mode** (D1 Quality mode stays default). Architecture = **first-chunk prelude + stream** with a global speaker registry. ElevenLabs uses a **fixed preset voice pool, not IVC cloning** (intermittent celebrity-block); OmniVoice keeps source cloning. *Revisit:* ElevenLabs cost runs high, a realtime EA local TTS appears, early-scene voice consistency proves bad (revisit online matching), or the 3-concurrent cap lifts.
