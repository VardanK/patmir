Patmir extension — options

Connect this extension to your local Patmir server. The token is auto-generated the first time you run patmir ui and printed on stderr.

Loopback only. Defaults to http://127.0.0.1:8765.
Stored locally in chrome.storage.local. Never sent to anywhere but your local server.
When a YouTube video has already been translated, play the dub automatically. You can still stop it from the popup; the choice is remembered per video.
Steers the Armenian toward age-appropriate wording. Nothing is ever cut, muted or bleeped — every line is still spoken, in gentler words. Each level is cached separately, so switching re-translates the video once.
Presses Skip Ad as soon as it appears. The dub pauses for an ad and resumes afterwards either way, so turning this off costs you nothing but the wait. If you already run an ad blocker, this never fires.
Off by default, and the only setting here that can affect playback. It writes to the player's position, so if ad detection is ever wrong it moves the video you are actually watching. It is now refused unless YouTube's own player reports an ad, the clip is short enough to be one, and its length does not match the video you opened — but the safe half of auto-skip is the checkbox above, and this is the half that isn't.
