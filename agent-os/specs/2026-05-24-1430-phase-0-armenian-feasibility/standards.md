# Standards for Phase 0 — Armenian Feasibility Gate

No standards apply to this work.

`agent-os/standards/index.yml` is currently empty (no standards have been authored for this project yet). Phase 0 is also a research/evaluation effort rather than production code, so even if standards existed for the eventual pipeline, most would not bind here.

When standards are added later, candidates worth surfacing for Phase 1 (not this phase) include configuration conventions and a `Stage` protocol — neither of which applies to a research harness.
